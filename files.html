TinyModem.h		Header only software audio modem library based on the arduino-audio-tools: FSK (compatible with minimodem), multi-tone FSK, PSK, OFDM, AX.25/APRS, ggwave, Olivia/Contestia, chirp spread spectrum, DTMF and packets with error correction. Include "AudioTools.h" before this file
 
TinyModemRTOS.h		TinyModem.h plus the stream classes which receive in a separate task (ModemStreamRTOS, MFSKStreamRTOS, PSKStreamRTOS, OFDMStreamRTOS, AX25StreamRTOS, GGWaveStreamRTOS). Supported on ESP32, on RP2040 with FreeRTOS (select Tools > Operating System > FreeRTOS SMP and include <FreeRTOS.h> before AudioTools.h) and on the desktop
