Detailed Description

OFDM modulator: the written bytes are collected into frames (up to OFDMConfig::max_frame bytes) which are transmitted with differential QPSK on all carriers. A frame is sent when it is full or when you call endTransmission() (or flush()).

A frame consists of a sync symbol (only even carriers, so the two halves are identical), a reference symbol, a header symbol with the length and the data symbols. Each symbol starts with a cyclic prefix.
