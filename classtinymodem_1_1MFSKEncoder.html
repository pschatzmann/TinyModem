Detailed Description

Multi-tone FSK modulator: converts the written bytes into 16 bit PCM audio. Each symbol is one of MFSKConfig::tones tones and carries log2(tones) bits (Gray coded, most significant bit first).

A transmission starts with a preamble (alternating lowest and highest tone) for the receiver's timing, followed by the sync symbols (see MFSKConfig::syncSymbol()) and the data. Call endTransmission() (or flush()) when the data is complete: the last symbol is padded with 0 bits and 2 symbols of silence mark the end.
