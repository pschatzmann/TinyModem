Detailed Description

Reed-Solomon code with lengths which are defined at runtime: it is identical to the code which is used by ggwave (Mike Lubinets' library): GF(256) with the polynomial 0x11d and the generator roots alpha^0 to alpha^(ecc-1). The parity bytes follow the message.
