Detailed Description

Multi-tone FSK demodulator: PCM audio data is written to the decoder and the decoded bytes are written to the output. The input can be 8, 16 or 32 bit signed samples with any number of channels (only MFSKConfig::channel is evaluated).

The decoder searches for the preamble, determines the symbol timing from the alternating preamble tones and waits for the sync symbols. Then each symbol is analyzed with one Goertzel filter per tone. The timing is tracked with an early/late gate, so small differences of the sample rates are corrected. The end of a transmission is detected when the signal is lost.

Status messages (### CARRIER and ### NOCARRIER) are written to the status output.

bool tinymodem::MFSKDecoder::hasHighTone ( float clock_error,

Quick check before the (expensive) acquisition: the preamble alternates the lowest and the highest tone, so the highest tone must be present in one of the next symbols. This rejects a steady tone (e.g. a carrier at the lowest tone), which would otherwise start an acquisition at each step.
