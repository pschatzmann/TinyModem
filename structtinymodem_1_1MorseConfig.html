Detailed Description

Configuration of the Morse code modem (MorseEncoder, MorseDecoder): a tone which is switched on and off (CW). The speed is defined in words per minute (PARIS): a unit (the length of a dot) is 1.2 / wpm seconds.

setMode() selects "morse" or "cw" (International Morse code, 20 wpm), "morse-american" (American Morse code), optionally with the speed, e.g. "morse-25", "morse-american-15" or "cw25".
