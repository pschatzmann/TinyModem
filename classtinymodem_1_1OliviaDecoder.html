Detailed Description

Olivia and Contestia demodulator (compatible with fldigi): the PCM audio data is written to the decoder and the decoded characters are written to the output. The input can be 8, 16 or 32 bit signed samples with any number of channels (only OliviaConfig::channel is evaluated).

The input is converted to 8000 Hz. Twice per symbol the tone energies are measured with an FFT and converted to soft bits for each possible frequency offset (+/- OliviaConfig::sync_margin FFT bins). For each time slice and frequency offset the last FEC block is decoded after every symbol. The synchronizer integrates the signal and noise of the decoded blocks over OliviaConfig::sync_integration blocks and selects the block timing and the frequency offset with the strongest signal. A block is provided if its signal to noise ratio is above OliviaConfig::sync_threshold. The idle character 0 is not provided.

Memory: about (2 * sync_margin + 1) * 3 * symbolsPerBlock() * (bits per symbol + 16) bytes plus 20 * symbolLen() bytes, e.g. 30 kB for olivia-32-1000.
