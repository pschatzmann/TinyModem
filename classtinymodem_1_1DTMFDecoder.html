Detailed Description

DTMF (touch tone) demodulator: the PCM audio data is written to the decoder and the received keys (0-9, *, #, A-D) are written to the output. The input can be 8, 16 or 32 bit signed samples with any number of channels (only DTMFConfig::channel is evaluated).

The 8 tones are measured with Goertzel filters over windows of 25.6 ms (205 samples at 8000 Hz). Four windows overlap, so that a new result is available every 6.4 ms. A key is detected when the strongest row and column tone are clearly above the other tones of their group (DTMFConfig::group_ratio_db), have a similar level (DTMFConfig::max_twist_db) and contain most of the signal energy. A key is reported after 3 consecutive detections and released after 3 windows without it. The same key is only reported again if it is at least half as strong as before: this ignores the echo at the end of a tone.

A transmission ends after DTMFConfig::rx_timeout_ms without a key: this is reported with ### NOCARRIER.
