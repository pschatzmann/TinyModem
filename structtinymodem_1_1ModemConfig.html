Detailed Description

Configuration of the FSK modem. The fields correspond to the command line options of minimodem. Call setMode() to select one of the predefined baud modes ("1200", "300", "rtty", "tdd", "same", "callerid", "uic-train", "uic-ground", "V.21" or any number N for a Bell-like N bps modem) first and then change the individual fields. Fields which are left at 0 (or -1) are derived automatically when the encoder or decoder is started.

◆ setMode()

bool tinymodem::ModemConfig::setMode ( const char * mode,
bool keep_options = false )
inline

Selects one of the predefined baud modes: returns false if invalid. All mode related fields (baud rate, frequencies, bandwidth, framing, sync, format) are reset first, so the result does not depend on a previous mode. With keep_options=true the data_bits and stop_bits which were set before are kept where minimodem allows options to override the mode (like the minimodem command line).
