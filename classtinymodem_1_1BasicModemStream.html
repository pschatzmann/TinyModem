Detailed Description

template<class Encoder, class Decoder, class Config>
class tinymodem::BasicModemStream< Encoder, Decoder, Config >

Arduino Stream API for a modem (encoder and decoder): the written characters are modulated to the audio output and the audio input is demodulated into characters that can be read. You can use only the output (transmit only), only the input (receive only) or both.

The received data is only processed when you call available(), read(), peek() or update(), so call one of them regularly in your loop(). No decoded data is lost: the input is only read while less than rx_buffer_size bytes are waiting to be read.
