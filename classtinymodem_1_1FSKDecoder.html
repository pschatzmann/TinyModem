Detailed Description

FSK demodulator: PCM audio data is written to the decoder and the decoded data is written to the output that was defined with setOutput(). Supported input formats are 8, 16 or 32 bit signed integer samples with any number of channels (only config.channel is evaluated). The decoding is compatible with minimodem –tx.

Status messages (### CARRIER and ### NOCARRIER) are written in the minimodem format to the Print defined with setStatusOutput().
