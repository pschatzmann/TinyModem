Detailed Description

Chirp spread spectrum demodulator (LoRa-like): the PCM audio data is written to the decoder and the payload of the received frames with a correct CRC is written to the output. The input can be 8, 16 or 32 bit signed samples with any number of channels (only CSSConfig::channel is evaluated).

The signal is mixed to the complex baseband and resampled to the bandwidth, so that a symbol has N = 2^SF samples. A symbol is multiplied with the conjugate chirp (dechirped): the result is a tone, whose FFT bin is the symbol value. The preamble is detected by the same bin in consecutive windows; the bins of the up and down chirps provide the time and frequency offset. During the frame the timing follows a different clock of the sender.

The receiver must use the same ecc_bytes as the transmitter.
