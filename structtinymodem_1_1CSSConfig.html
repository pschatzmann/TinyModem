Detailed Description

Configuration of the chirp spread spectrum modem (CSSEncoder, CSSDecoder), which works like LoRa in the audio band: each symbol is a linear chirp over the bandwidth, which starts at one of N = 2^SF frequencies and carries SF bits (SF = spreading factor). The signal can be received far below the noise level and is robust against frequency offsets, different clocks and echoes. It is not compatible with LoRa radios.

A frame starts with preamble_symbols up chirps and 2 down chirps, followed by the header (length, Reed-Solomon protected) and the payload (CRC-16 and ecc_bytes Reed-Solomon parity bytes).

setMode() selects "css5" to "css10" (SF, 1000 Hz bandwidth) or e.g. "css7-500" or "css9-2000" (SF and bandwidth). "css" is "css7".
