Detailed Description

FSK modulator: converts the written characters into 16 bit PCM audio which is written to the defined output. The generated signal is compatible with minimodem –rx.

The tones are produced by a SoundGenerator<int16_t>. By default this is a FSKToneGenerator, which reproduces minimodem's signal. You can replace it with setGenerator(): the generator must change the frequency immediately and keep the phase continuous in setFrequency() - e.g. the AudioTools FastIntSineGenerator, which needs no floating point and is a good choice for MCUs without FPU. FloatSineGenerator, FastSineGenerator and SineFromTable are not suited. The generator's amplitude is full scale: ModemConfig::volume is applied by the encoder.

A transmission starts with leader (mark) bits, followed by the optional sync bytes and the data frames. Call endTransmission() (or flush()) to send the trailer bits when there is no more data to send.
