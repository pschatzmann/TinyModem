Detailed Description

Olivia and Contestia modulator (compatible with fldigi): the written characters are collected in blocks of bitsPerSymbol() characters, which are FEC encoded into 64 (Contestia: 32) symbols. Each symbol is a tone with a raised cosine envelope over two symbol periods, so consecutive symbols overlap by half.

A transmission starts and ends with the fldigi start/stop tones (at the band edges). Call endTransmission() (or flush()) when the data is complete: an incomplete block is filled with 0 (the idle character). Olivia sends 8 bit characters escaped with 127, like fldigi: the character 127 itself can't be sent and is ignored.
