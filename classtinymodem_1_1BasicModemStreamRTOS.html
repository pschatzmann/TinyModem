Detailed Description

template<class Base>
class tinymodem::BasicModemStreamRTOS< Base >

BasicModemStream which receives in a separate task (FreeRTOS on ESP32 and RP2040, a std::thread on the desktop): the task reads the audio input and decodes it, so the decoding does not block your loop() and no audio is lost while loop() is busy. available(), read() and peek() only access the received data and can be called from any task.

Transmitting (write(), print(), flush()) happens in the calling task like in the BasicModemStream. The status output (setStatusOutput()) is written by the receive task.
