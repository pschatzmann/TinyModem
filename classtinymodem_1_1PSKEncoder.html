Detailed Description

PSK modulator (compatible with fldigi): the written bytes are Varicode encoded and each symbol is a phase step with a cosine shaped transition from the previous phase.

BPSK (PSK31): the characters are separated by "00", a 0 bit is a phase reversal, a 1 bit keeps the phase. QPSK: each bit is encoded by a rate 1/2 convolutional code into a phase step of 0, 90, 180 or 270 degrees. 8PSK: the MFSK Varicode bits are sent in groups of 3 as phase steps of 45 degrees.

A transmission starts with phase reversals (preamble). Call endTransmission() (or flush()) when the data is complete: the postamble is sent (BPSK and 8PSK: steady carrier, QPSK: encoded 0 bits) and the signal fades out.
