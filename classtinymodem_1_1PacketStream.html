Detailed Description

template<uint8_t MAX_PAYLOAD = 64, uint8_t ECC_BYTES = 16>
class tinymodem::PacketStream< MAX_PAYLOAD, ECC_BYTES >

Reliable data transfer over any Stream (e.g. a ModemStream, an MFSKStream or a Serial): the written data is sent in packets with CRC-16 and Reed-Solomon forward error correction, and only correct data can be read. Corrupted packets which can't be corrected are dropped.

A packet is sent when MAX_PAYLOAD bytes were written or when you call flush(), which also calls flush() of the underlying stream (which ends the transmission of a modem). Both sides must use the same template parameters.

Template Parameters
MAX_PAYLOADmaximum number of data bytes per packet
ECC_BYTESnumber of Reed-Solomon parity bytes: up to ECC_BYTES / 2 wrong bytes per packet are corrected
