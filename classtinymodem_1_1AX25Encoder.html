Detailed Description

AX.25 packet radio modulator (APRS, 1200 baud AFSK). The written data is converted to AX.25 frames, which are sent with HDLC framing (flags, bit stuffing, frame check sequence) and NRZI coding.

In AX25Format::TEXT each line (terminated by '
') is a frame in the monitor format SRC>DEST,DIGI1,DIGI2:info. In AX25Format::KISS the data consists of KISS frames. A frame is sent as soon as it is complete: the first frame of a transmission is preceded by tx_delay_ms of flags. Call endTransmission() (or flush()) to send the tail flags.

AX25Config::layer2 selects FX.25 (the HDLC frame is sent as data of a Reed-Solomon code word with a correlation tag) or IL2P (preamble 0x55, sync word, scrambled header and payload with Reed-Solomon parity, without NRZI) instead of standard AX.25.
