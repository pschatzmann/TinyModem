Detailed Description

Configuration of the OFDM modem (OFDMEncoder, OFDMDecoder): the data is transmitted in parallel on carriers subcarriers with differential QPSK (2 bits per carrier and symbol). Each symbol has a cyclic prefix (guard interval) against echoes.

setMode() selects "ofdm16", "ofdm32" or "ofdm64": all use the band from 1000 Hz to about 3000 Hz and transmit 3200 bit/s. More carriers result in longer symbols with a longer guard interval.
