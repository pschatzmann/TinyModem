Detailed Description

OFDM demodulator: the PCM audio data is written to the decoder and the decoded frames are written to the output. The input can be 8, 16 or 32 bit signed samples with any number of channels (only OFDMConfig::channel is evaluated).

The start of a frame is found with the Schmidl & Cox method: the sync symbol consists of two identical halves, which are detected with a sliding autocorrelation. The reference symbol provides the initial phase of all carriers and an estimate of the frequency offset and timing drift, which are tracked during the frame. The carriers are analyzed with a DFT.
