Detailed Description

template<uint8_t MAX_PAYLOAD = 64, uint8_t ECC_BYTES = 16>
class tinymodem::PacketEncoder< MAX_PAYLOAD, ECC_BYTES >

Splits the written data into packets with a CRC-16 and Reed-Solomon forward error correction, which are framed with HDLC-style flags (0x7E) and byte stuffing, and writes them to the output (e.g. a ModemStream).

A packet is sent when MAX_PAYLOAD bytes were written or when you call flush(). The packet is transmitted as payload + CRC + ECC_BYTES parity bytes: shorter packets use a shortened Reed-Solomon code, so they don't need any padding. The receiver (PacketDecoder) corrects up to ECC_BYTES / 2 wrong bytes per packet.

Template Parameters
MAX_PAYLOADmaximum number of data bytes per packet
ECC_BYTESnumber of Reed-Solomon parity bytes per packet
