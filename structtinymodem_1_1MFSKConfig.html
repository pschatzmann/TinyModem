Detailed Description

Configuration of the multi-tone FSK modem (MFSKEncoder, MFSKDecoder). Each symbol is one of tones tones and carries log2(tones) bits. The tones are base_freq + i * tone_spacing.

Use setMode() to select a predefined mode: "mfsk4", "mfsk8", "mfsk16", "mfsk32" or "mfsk64". All of them use tones between 1000 and 3000 Hz, so they work with speakers, microphones and telephone lines. More tones are slower but more robust against noise.
