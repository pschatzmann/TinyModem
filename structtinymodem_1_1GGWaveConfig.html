Detailed Description

Configuration of the ggwave compatible modem (GGWaveEncoder, GGWaveDecoder). Each message (up to 140 bytes) starts and ends with a marker and is protected by Reed-Solomon codes. Each byte is sent as 2 of 16 tones which are transmitted at the same time.

setMode() selects the protocol: "ggwave-normal", "ggwave-fast", "ggwave-fastest" (audible, 1875 - 6375 Hz), "ggwave-u-normal", "ggwave-u-fast", "ggwave-u-fastest" (ultrasound, 15000 - 19500 Hz), "ggwave-dt-normal", "ggwave-dt-fast" and "ggwave-dt-fastest" (dual tone, 1125 - 2625 Hz). "ggwave" is "ggwave-fast", the default of the ggwave tools. The variable length format is used, which is the default of ggwave. The mono-tone (MT) protocols and the fixed length format are not supported.

The sample rate must be a multiple of 46.875 Hz * 4, e.g. 48000 or 24000 Hz (44100 Hz is not supported), and high enough for the highest tone.
