Detailed Description

ggwave compatible modulator: the written bytes are collected into messages of up to 140 bytes. A message is sent when it is full or when you call endTransmission() (or flush()). The generated audio is identical to the audio of ggwave (variable length format).

A message consists of the start marker (16 frames), the Reed-Solomon coded length (3 bytes), the Reed-Solomon coded payload and the end marker (16 frames). Each byte is sent as 2 simultaneous tones (one of 16 tones for each nibble) and each symbol lasts GGWaveProtocol::frames_per_tx frames.
