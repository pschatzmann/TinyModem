# AX.25 (APRS and packet radio)

AX.25 is the packet radio protocol of amateur radio, which is used by APRS (position reports, messages and weather data). The physical layer is Bell 202 AFSK with 1200 baud (1200 and 2200 Hz), NRZI coding and HDLC framing: frames are delimited by flags (`0x7E`), long runs of 1 bits are broken up by bit stuffing, and each frame ends with a frame check sequence (CRC). A frame contains a destination, a source and up to 8 digipeater addresses, followed by the information field.

**Advantages**

- Compatible with direwolf, multimon-ng, APRS programs and hardware TNCs. Tested with direwolf in both directions.
- Each frame has a CRC: frames with errors are dropped.
- Text format for APRS (`SRC>DEST,PATH:info`, like direwolf) and KISS format for packet radio applications.

**Disadvantages**

- Fixed at 1200 baud.
- Only frames with addresses, no plain byte stream.
- Transmitting on the radio needs an amateur radio license.
- At 8000 Hz a bit has only 6.7 samples: use 22050 Hz or more, like direwolf.
- On direwolf's test with 100 frames of increasing noise, the decoder finds a few frames less than direwolf (68 against 72).

## Usage

The data has one of two formats (`AX25Config::format`):

- `AX25Format::TEXT` (default): one frame per line in the monitor format `SRC>DEST,DIGI1,DIGI2:info`, for example `N0CALL-9>APRS,WIDE1-1,WIDE2-1:!4903.50N/07201.75W-Hello`. A digipeater which has repeated the frame is marked with a `*`.
- `AX25Format::KISS`: KISS frames (`0xC0 0x00 frame 0xC0`, with `0xC0` and `0xDB` escaped), the format of packet radio applications and TNCs.

```cpp
I2SStream i2s;
AX25Stream aprs(i2s, RXTX_MODE);

void setup() {
  AX25Config cfg = aprs.defaultConfig();
  cfg.sample_rate = 22050;
  ...
  aprs.begin(cfg);
}

void loop() {
  aprs.println("N0CALL-9>APRS,WIDE1-1:!4903.50N/07201.75W-TinyModem");
  aprs.flush();  // ends the transmission
  delay(60000);
}
```

```sh
echo "N0CALL>APRS:>Hello" | tinymodem --tx -f aprs.wav aprs
tinymodem --rx -f aprs.wav aprs            # monitor format
tinymodem --rx --kiss -f aprs.wav aprs     # KISS frames
```

`AX25Config`, `AX25Encoder`, `AX25Decoder`, `AX25Stream`, `AX25StreamRTOS` and `AX25Frame` (conversion between frames, the text format and KISS) are the AX.25 classes. See the [aprs-beacon](../examples/aprs-beacon) example. On the command line, `-R`, `-v`, `-M` / `-S` (tones), `-q`, `--kiss` and `--Xrxnoise` are supported; `--tx-carrier` sends flags. `aprs` and `ax25` are the same mode.

| `AX25Config` field | Default | |
|---|---|---|
| `format` | `TEXT` | `TEXT` or `KISS` |
| `baud_rate` | 1200 | Bits per second |
| `mark_freq` / `space_freq` | 1200 / 2200 | Tones (Hz) |
| `volume` | 1.0 | Transmit amplitude |
| `tx_delay_ms` | 300 | Flags before the first frame (time for the transmitter to switch on) |
| `tx_tail_ms` | 50 | Flags after the last frame |
| `channel` | 0 | Receiver: input channel |
| `sample_rate`, `channels`, `bits_per_sample` | 48000, 1, 16 | Audio format |

A frame is sent as soon as its line (or KISS frame) is complete. Call `flush()` (or `endTransmission()`) after the last frame of a transmission. At the end, the decoder reports `### AX25 frames=… fcs_errors=… ###`.

## How it works

The receiver measures the energy of the mark and space tones with sliding correlators over one bit (rotating phasors, so there is no `sin()` per sample). A digital PLL recovers the bit clock from the tone changes. The bits are NRZI decoded (no tone change = 1), the flags are detected, the stuffed bits are removed and the frame check sequence is verified. Only correct frames are provided.

## Measured performance

- direwolf (`atest`) decodes all frames of `tinymodem`, and `tinymodem` decodes all frames of direwolf's `gen_packets`, with identical text.
- 100 frames with increasing noise from `gen_packets -n 100`: `tinymodem` 68, direwolf 72 at 44100 Hz; 68 and 70 at 48000 Hz; 50 and 50 at 22050 Hz.
- Loopback at 48000 Hz: no errors with noise 0.5 and with ±1% different clocks. At 8000 Hz: all frames with noise 0.3, but frames are lost with a clock difference of −1%.
